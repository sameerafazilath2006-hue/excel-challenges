
Excel Assignment
Overview

This project focuses on basic data exploration and analysis using Microsoft Excel. The dataset contains product-related information such as product name, brand, price, quantity, and category.

The objective of this assignment is to practice:

Data exploration
Data cleaning
Sorting and filtering
Basic analysis using Excel functions
Understanding business insights from raw data
Dataset Information

The dataset includes the following columns:

Column Name	Description

Product ID	Unique identifier for products
Product Name	Name of the product
Brand Name	Brand associated with the product
Price ($)	Product price in USD
Quantity	Available quantity
Category	Product category

Tools Used

Microsoft Excel
Excel Functions
Sorting & Filtering
Basic Data Analysis Techniques

Tasks Performed

Explored the dataset structure
Checked column information
Identified categories and product details
Analyzed prices and quantities
Applied Excel functions for data understanding
Organized and filtered data for better insights

Key Insights

Electronics products have higher average prices.
Fashion and grocery categories contain lower-priced products.
Quantity distribution varies across categories.
Brand-wise analysis helps identify product distribution.
